# RayLibBase
This is a basic C# template for RayLib projects.

It's basically code used for learning RayLib but refactored for further use.

# Exporting a template

At this moment, if you'd like to use this project as a template you need to export it manually.

To do that

1. Open the solution in your Visual Studio.
2. From the menu Project -> Export Template
3. Pick the Project Template option, and pick the csproj (so far there's only one)

After that, you will not only be taken to where the exported template is stored.

You will also be able to use it when creating new projects from Visual Studio.
